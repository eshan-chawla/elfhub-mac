# Files

- [A Conversation Turn: Voice and Chat](conversation-turn.md) - How a push-to-talk or typed turn runs end to end. Covers the shortcut tap and drawing, the prefetched screenshot, transcription and consent replies, the shared CompanionTurnPipeline (prompt, tools or tags, the tools-only follow-up, decoding, history), streaming captions and sentence-by-sentence speech, cancellation, errors, and recording into chat.
- [The Notepad: Written Explanations in Step with Speech](notepad.md) - How elfhub writes steps, commands or code into a floating notepad while it talks. Covers the silent NOTEPAD tags, how each line is tied to the next sentence and shown as speech reaches it, pacing, the draggable window with copy and close, and how the notepad is saved in chat and in the model's history.
- [Screen Capture, Pointing, Annotations, Drawing, and Actions](screen-targeting-and-actions.md) - How elfhub sees the screen and acts on it. Covers capturing the display under the cursor at a size each model can handle, the coordinate spaces and conversions between them, decoding guidance from tags or tools, placement refined with Accessibility, how long things stay on screen, the user's own drawing, and consent-gated clicks, typing, scrolling and keys.
